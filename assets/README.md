# Assets

Сюда нужно положить реальные изображения и визуальные материалы.

Ожидаемые файлы:

- `hero-family.png` — главное изображение семьи в hero-блоке.
- `checklist-preview.png` — превью чек-листа "Семейный план на неделю".
- `telegram-preview.png` — мокап Telegram-канала.
- `og-image.png` — картинка для превью ссылки в Telegram/соцсетях.
- `favicon.svg` — favicon.
- `logo.svg` — опционально, если решим заменить CSS-логотип на SVG.

Важно:
- В коде сейчас используются placeholder-блоки без реальных картинок.
- Когда изображения будут готовы, можно заменить `.media-slot` на `<img>` или сделать фон через CSS.
