# Assets

Сюда нужно положить реальные изображения и визуальные материалы.

Ожидаемые файлы:

- `logo-mark.png` — знак логотипа: улыбка + два кружка. Прозрачный фон, без текста.
- `hero-family.png` — главное изображение семьи в hero-блоке.
- `checklist-preview.png` — превью чек-листа "Семейный план на неделю".
- `telegram-preview.png` — мокап Telegram-канала.
- `og-image.png` — картинка для превью ссылки в Telegram/соцсетях.
- `favicon.svg` — favicon.
- `logo.svg` — опционально, если решим заменить HTML-логотип на цельный SVG.

Рекомендации:

- `logo-mark.png`: 512x512 px, прозрачный фон.
- `hero-family.png`: желательно 1200x900 px или больше, PNG/WebP.
- `checklist-preview.png`: вертикальный mockup документа.
- `telegram-preview.png`: mockup телефона или скрин канала.
- `og-image.png`: 1200x630 px.
